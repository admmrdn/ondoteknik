# Website CV Ondo Teknik Machine

Website statis responsif berbasis HTML, CSS, dan JavaScript.

## Menjalankan secara lokal
1. Ekstrak folder `ondo_teknik_website`.
2. Buka folder tersebut di VS Code.
3. Jalankan `index.html` menggunakan ekstensi Live Server, atau jalankan:
   `python -m http.server 8000`
4. Buka `http://localhost:8000`.

## Struktur
- `index.html` — halaman utama.
- `assets/` — foto produk, dokumentasi proyek, dan katalog.

## Catatan konten
Konten profil, produk, spesifikasi, pengalaman proyek, garansi, alamat, dan nomor kontak dirangkum dari Company Profile CV Ondo Teknik Machine yang diberikan. Foto katalog Fire Pump/sparepart menggunakan gambar katalog yang disertakan.
Harga pada gambar katalog ditampilkan sebagai materi visual; konfirmasi harga dan stok langsung ke perusahaan sebelum transaksi.
